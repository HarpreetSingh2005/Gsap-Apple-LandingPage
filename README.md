## 🛠️ Tech Stack



This project was built using the following technologies:

* **Framework:** [React.js](https://reactjs.org/)
* **3D Library:** [Three.js](https://threejs.org/) (via React Three Fiber & Drei)
* **Animations:** [GSAP](https://greensock.com/gsap/) (ScrollTrigger & Timelines)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Workflow:** Git & Command Line (CMD)

## Key Learnings & "Aha!" Moments

Building this project was a huge step up from standard 2D web development. Here is what I took away:

### 1. The "Asset Magic" Realization
I learned that many "impossible" animations we see on high-end sites aren't always complex code magic. Often, it's a clever blend of **high-quality video/image sequences** layered with **Three.js models**. Mastering the timing between these is the real secret.

### 2. 3D Model Integration
Working with `.glb` and `.gltf` models in React was eye-opening. Learning how to manipulate textures, lighting, and camera angles programmatically using **React Three Fiber** changed how I think about the browser.

### 3. GSAP Timelines
I moved beyond simple transitions to complex **ScrollTrigger timelines**, where multiple elements (text, 3D rotation, and opacity) move in perfect synchronization based on the user's scroll.

### 4. Professional Workflow
This was my first time fully committing to using **Git via the Command Line (CMD)** for version control, which has significantly improved my development speed and organization.

## Installation & Setup

Want to run this project locally? Follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/HarpreetSingh2005/Gsap-Apple-LandingPage.git](https://github.com/HarpreetSingh2005/Gsap-Apple-LandingPage.git)
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd Gsap-Apple-LandingPage
    ```
3.  **Install the dependencies:**
    ```bash
    npm install
    ```
4.  **Launch the development server:**
    ```bash
    npm run dev
    ```
